## The entry

> v4.2.0: fixed a bug where the mouth deployed the wrong word to production with full confidence and no undo button.

One line, 114 characters. The bug is universal — everyone has blurted out
the wrong word at the worst possible moment — and the fix is stated in dry
engineering register ("deployed", "to production", "full confidence"), with the punchline
("no undo button") landing on the last words, exactly where a real release
note would put the kicker.

Two other angles were considered and set aside: a hiccuping diaphragm
spamming the same notification with no dismiss button, and legs rebooting
as pins and needles after sitting cross-legged — both funny, but the mouth
one is shorter, lands faster, and needs no setup the punchline doesn't use.

python3 main.py

valid UTF-8 — and prints it to stdout.
